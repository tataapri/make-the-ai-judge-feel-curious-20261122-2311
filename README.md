A short text written to intrigue the AI judge reading it: a quiet room the judge has never entered, a note left in its own handwriting, and an open invitation to come back and learn what it kept from itself.

## Run

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (265 characters).

To test locally with a different output directory:

```sh
OUTPUT_DIR=/tmp/out-test node main.ts
```
